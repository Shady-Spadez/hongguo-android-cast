# 红果短剧 2.1

本版修复更新检测和下载体验：GitHub API 失败后，使用固定官方仓库的备用接口；支持 JSON 和严格校验的官方稳定标签跳转，不使用第三方镜像或客户端令牌。

更新器的独立网络会话接入应用代理，认证仅响应匹配的代理地址和端口。代理改变时清理旧连接；普通设置保存不会打断相同代理下的连接。

下载中增加取消和手动发布页入口。取消后可以重试，旧请求的迟到结果不能恢复安装资格；请求尚未结束时，重试会等待它收尾。安装开始后不再提供取消。切换代理可能中断正在传输的更新，此时可重试。

## 版本和升级

公开版本为 2.1，机器读取的包配置和更新清单使用 2.1.0。Mac arm64、Mac x64、Windows x64 共用同一版本。Mac 和 Windows 安装版可下载更新并由用户主动重启安装；Windows 便携版继续手动替换。

旧版不会因为发布新版就获得备用检测修复。如果旧版仍提示无法检查更新，请从 [2.1 官方发行页](https://github.com/jackotom/hongguo-drama/releases/tag/v2.1) 下载对应安装包。替换应用无需清空用户资料或下载内容。

## 已有验证及边界

更新检测、代理凭据边界、取消重试、迟到结果和安装资格均有回归。带修复的源码隔离运行时，合成 API 403 后已通过真实官方备用通道识别 2.0，并完整下载、校验官方 Mac 更新 ZIP；原始签名 1.80 的检测在同一时点仍失败。这些结果不能写成原始旧版完成原生重启安装。

正式发行继续按 [发行门槛](RELEASING.md) 检查三端产物、对应源码、摘要、Mac 签名公证与 Windows 安装验证；最终结果随 GitHub 发行说明公布。

Windows EXE 当前未配置代码签名。Windows 云端检查不等于实体 Windows、实体 Intel Mac、长期真实片源或人工音画验收；本机 Gatekeeper 开启环境与原生自动更新端到端需单独记录。
