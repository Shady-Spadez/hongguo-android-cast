# 红果短剧 2.0

本版合入代理与文件访问安全修复，并补齐实际使用流程中的回归问题。

- 切换下载目录后，已登记的历史视频仍可定位与兼容转码；未登记路径和符号链接逃逸仍被拒绝。
- 代理密码保存、替换、清除后立即刷新状态；普通设置保存不重放密码。粘贴地址中的密码也不会回传页面。
- 修复 IPv6 代理地址与认证匹配；跟随系统代理恢复启动时配置。
- 保留 PR #29 的设置白名单、Windows 保留名处理、正式包 FFmpeg 限制、下载摘要校验与 Electron 更新。
- 对外版本、标签及下载名称统一使用两段版本 **2.0**。旧三段版本安装包仍能参与升级比较。

## 安装与升级

Mac：退出旧应用，将 DMG 中的“红果短剧”拖入“应用程序”并替换，再从“应用程序”打开。不要继续打开旧 DMG 内的副本。保留原有下载目录和资料，无需清空数据。

Windows：使用 `hongguo-downloader-2.0-win-x64-setup.exe` 安装版。旧便携版是另一个文件，安装新版后请从新安装入口启动；旧便携文件不会被安装器自动替换。便携版仍需手动更新。

1.80 安装版支持应用内下载后重启安装；1.75 及更早版本首次需要手动安装新版。

Windows 安装程序未配置 Authenticode 签名。实体 Windows/GPU、实体 Intel Mac、长期上游下载覆盖应与 CI 和 Rosetta 验证分开记录。

本文不单独证明已发布；正式资产、签名公证及实际验收结果以对应 Release 记录为准。
