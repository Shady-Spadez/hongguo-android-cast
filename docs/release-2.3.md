# 红果短剧 2.3

修复发现短剧与热播推荐的红果目录请求没有使用应用浏览器网络层的问题。现在目录与榜单通过同一浏览器会话请求，使应用中的系统、直连和自定义代理设置一致生效；保留超时、响应大小限制和公开数据读取边界。连接被中断时会提示重试或切换来源。

热播推荐新增来源选择。红果不可用时可切换西饭、河马及已启用的自定义源；红果保留真实热播榜，其它来源显示实际目录，不表示热播排名。换源时清除旧片单、旧错误和播放解析状态，迟到请求不会覆盖当前来源。摇一摇与剧库播放入口继续保留。

## 版本与安装

公开版本 2.3、标签 v2.3；机器配置和更新清单使用 2.3.0。三端共用此版本：Mac arm64、Mac x64、Windows x64。无需清空原资料和视频。Mac 首次安装将应用拖入“应用程序”；Windows 推荐 setup 安装版，便携版手动替换。

## 验证范围

目录故障模拟与换源至剧库播放的组件回归已通过。本机真实 Electron 在直连和系统模式下均获取到分类及热播榜。未能复现 #33 反馈者所在网络的原始断连，仍需其更新后复测；本版不承诺解决所有网络、设备或上游限制。

发行包签名、公证、Windows 安装升级和下载校验结果以 GitHub 发行页为准。Windows EXE 尚未签名。本轮指定的视频验收素材缺失，未做实际视频播放验收；未覆盖实体 Windows、实体 Intel Mac、启用 Gatekeeper 的干净环境及长期播放。不以组件模拟或云端检查替代这些实测。
